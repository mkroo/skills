# Google AdSense Approval Criteria

AdSense 심사 기준과 일반적인 거절 사유 정리. 이 문서는 Google의 공개 가이드라인을 기반으로 정리한 것이며, 실제 심사 기준은 Google 내부에서 결정됩니다.

## 필수 요구사항

### 1. 콘텐츠 충분성

- 각 페이지에 최소 200~300자 이상의 고유한 텍스트 콘텐츠
- 최소 5~10개 이상의 페이지 (단일 페이지 사이트는 거절 가능성 높음)
- "공사 중", "준비 중", "Coming soon" 페이지 없어야 함
- Lorem ipsum, placeholder 텍스트 없어야 함
- 다른 사이트에서 복사한 콘텐츠 없어야 함

### 2. 필수 페이지

- **개인정보처리방침 (Privacy Policy)** — 필수. 데이터 수집, 쿠키, 광고에 대한 고지 포함
- **이용약관 (Terms of Service)** — 권장
- **소개 (About)** — 권장. 사이트/서비스가 무엇인지 설명
- **문의 (Contact)** — 권장. 이메일 또는 문의 양식

### 3. 네비게이션

- 글로벌 네비게이션 (헤더/메뉴) 존재
- 모든 페이지에서 홈으로 돌아갈 수 있어야 함
- 푸터에 개인정보처리방침 링크 포함
- 내부 링크가 잘 연결되어 있어야 함 (고립된 페이지 없음)

### 4. 기술 요구사항

- **HTTPS** — 필수
- **robots.txt** — Googlebot 크롤링 허용
- **ads.txt** — AdSense 승인 후 필수 (신청 전에도 권장)
- **sitemap.xml** — 권장 (Google Search Console 등록에 도움)
- **모바일 반응형** — viewport meta 태그, 가로 스크롤 없음
- **빠른 로딩** — 5초 이내 (Core Web Vitals 양호)

### 5. 광고 정책 준수

- 성인 콘텐츠, 폭력, 불법 콘텐츠 없음
- 저작권 침해 콘텐츠 없음
- 오해의 소지가 있는 콘텐츠 없음
- 자동 리디렉트 없음
- 전체 화면 팝업/인터스티셜 광고 없음 (페이지 로드 시)

## 일반적인 거절 사유

### "저가치 콘텐츠 (Low-value content)"

가장 흔한 거절 사유. 원인:
- 페이지 수가 너무 적음
- 페이지당 텍스트가 너무 짧음
- 자동 생성된 콘텐츠
- 다른 사이트에서 복사한 콘텐츠
- 의미 없는 콘텐츠 (키워드 나열 등)

### "사이트가 작동하지 않음 (Site not working)"

- robots.txt가 Googlebot 차단
- 서버 에러 (5xx)
- 느린 로딩
- JavaScript 렌더링 의존 (SSR 없이 CSR만 사용)

### "유용하지 않은 페이지로의 이동 (Navigational issues)"

- 깨진 링크 (404)
- 네비게이션 메뉴 없음
- 고립된 페이지 (다른 페이지에서 접근 불가)

### "사이트 정책 위반 (Policy violations)"

- 개인정보처리방침 없음
- 금지된 콘텐츠 포함
- 사용자 경험 저해 (과도한 팝업 등)

## 체크리스트 요약

```
Infrastructure:
  [ ] HTTPS 사용
  [ ] robots.txt — Googlebot 허용
  [ ] ads.txt 존재
  [ ] sitemap.xml 존재

Required Pages:
  [ ] 개인정보처리방침 페이지 존재
  [ ] 개인정보처리방침에 쿠키/광고 고지 포함
  [ ] 소개 또는 문의 페이지 존재

Content:
  [ ] 최소 5~10개 페이지
  [ ] 각 페이지 200자 이상 고유 콘텐츠
  [ ] placeholder/dummy 텍스트 없음
  [ ] 복사 콘텐츠 없음

Navigation & UX:
  [ ] 글로벌 네비게이션 존재
  [ ] 푸터에 개인정보처리방침 링크
  [ ] 모바일 반응형 (viewport meta)
  [ ] 가로 스크롤 없음
  [ ] 전체 화면 팝업 없음

SEO:
  [ ] 각 페이지 고유 <title>
  [ ] 각 페이지 고유 <meta description>
  [ ] 5초 이내 로딩
```
